Moderation tools and messages

Moderation notices may be delivered by Discord direct message, but delivery is not guaranteed. A user may have DMs closed, may block the bot, or Discord may reject delivery. A failed DM does not necessarily mean the moderation action failed. Server moderators should check the bot's moderation logs or the relevant server state.

Automated detection can make mistakes. Server administrators should review configuration and use appropriate discretion. HODOR does not guarantee that every violation will be detected or that every moderation action will be correct.
