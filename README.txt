HODOR Terms of Service site

Files:
- index.html: self-contained responsive Terms of Service website (HTML/CSS/JS).

Before publishing:
1. Open index.html and replace [ADD YOUR OFFICIAL DISCORD SUPPORT INVITE] and [ADD A SUPPORT EMAIL, IF AVAILABLE] with contact details you control, or remove the unused line.
2. Review the terms for your actual bot features and how you operate it. This is a starter template, not legal advice; consider qualified legal review before relying on it.
3. Host index.html at a public HTTPS URL. For example, create a GitHub repository, upload index.html as the root file, enable GitHub Pages in repository Settings > Pages, and wait for the public site URL. Netlify Drop is another option for a static site.
4. Paste the resulting URL into Discord Developer Portal > your application > General Information > Terms of Service URL.

The page includes responsive layout, dark/light theme toggle, section navigation, terms search, collapsible FAQs, and a copy-link control. No external libraries are required.
